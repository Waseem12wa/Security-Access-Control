TASK 2 - Security Access Control System
Demo Script (Scenario + Implementation Inspection)

Scenario Demonstration (C)
1) Run the demo:
   java -cp target\classes com.coursework.accesscontrol.demo.AccessControlDemo

2) Observe printed outcomes:
   - GUEST (user1)
     - Allow: READ Printer (PUBLIC)
     - Deny:  READ Exam Paper (CONFIDENTIAL)
   - STUDENT (user2)
     - Allow: READ Lecture Material (INTERNAL)
     - Deny:  WRITE Exam Paper (CONFIDENTIAL)
   - STAFF (user3)
     - Allow: READ Lecture Material (INTERNAL)
     - Deny:  READ Exam Paper (CONFIDENTIAL)

3) Observe logged messages:
   The demo prints "=== Access Log ===" and then log lines in the form:
   dd-MM-yyyy HH:mm, userId, ROLE, ResourceName, READ/WRITE, ALLOW/REFUSE
   Each ALLOW/REFUSE corresponds to the above allow/deny cases.

Implementation Inspection (D)
3) Most challenging design pattern explanation:
   Chain of Responsibility is implemented in:
   com.coursework.accesscontrol.auth.RuleChainAccessAuthorizer#authorize(...)
   Each role-specific rule implements:
   com.coursework.accesscontrol.auth.rules.AccessRule#evaluate(...)
   The chain tries rules in order and returns the first applicable decision; otherwise defaults to REFUSE.

4) Most challenging JUnit test explanation:
   com.coursework.accesscontrol.AccessControlPolicyTest#studentDeniedWriteConfidentialAndLogged
   The test checks:
   - decision is REFUSE for STUDENT WRITE on CONFIDENTIAL
   - resource content is not modified
   - a REFUSE log entry is recorded correctly
